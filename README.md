# WellBridge AI

**Earlier Support. Trusted Care. Better Wellbeing.**

Nigeria-first, multi-country African mental-wellbeing support and care-navigation prototype built for Microsoft Azure.

> Prototype only; not a live healthcare service. It does not diagnose, prescribe, dispatch emergency services or complete live referrals. Do not enter patient records. AI and live referrals remain disabled pending clinical, privacy and operational approval.

The full source package and Azure deployment preparation are being added in the initial project commit.
